Shared infrastructure

This document uses the same Wikidata-to-Wikipedia-presence pipeline as the Latin America companion document. Two project-level helper files provide the core functionality:

  • wikidata_presence_matrix.R — builds a presence/absence matrix of Wikipedia sitelinks for all instances of a Wikidata class.
  • R/get_wikidata_instances.R — batched wbgetentities fetcher with resume support.

Featured languages for this analysis: English (en), French (fr), Arabic (ar), and Swahili (sw).

# ---- SPARQL helper ----------------------------------------------------------
sparql_query <- function(query) {
  r <- GET(
    "https://query.wikidata.org/sparql",
    query = list(query = query, format = "json"),
    user_agent("wiki-graph-admin-presence")
  )
  if (status_code(r) != 200) stop("SPARQL query failed: HTTP ", status_code(r))
  res <- fromJSON(content(r, "text", encoding = "UTF-8"))
  if (length(res$results$bindings) == 0) return(tibble())
  as_tibble(res$results$bindings) |>
    mutate(across(everything(), ~ .x$value))
}

# ---- Fetch or resume --------------------------------------------------------
fetch_or_resume <- function(class_qid, slug, n_expected,
                            prefix     = "ssa_adm2",
                            languages  = NULL,
                            batch_size = 30,
                            limit      = 2000) {
  cache_file <- file.path(cache_dir, paste0(prefix, "_", slug, ".rds"))

  if (file.exists(cache_file)) {
    partial <- readRDS(cache_file)
    n_done  <- nrow(partial$instances)
    message(slug, ": cache hit (", n_done, "/~", n_expected, " items). ",
            "Resuming if incomplete…")
    result <- resume_wikidata_instance_wikipedia_presence(
      partial_result = partial,
      class_qid      = class_qid,
      languages      = languages,
      limit          = limit,
      batch_size     = batch_size
    )
  } else {
    message(slug, ": no cache. Fetching fresh…")
    result <- wikidata_instance_wikipedia_presence(
      class_qid  = class_qid,
      languages  = languages,
      limit      = limit,
      batch_size = batch_size
    )
  }

  saveRDS(result, cache_file)
  message(slug, ": done — ", nrow(result$data), " items → ", cache_file)
  result
}

# ---- Combiner ---------------------------------------------------------------
combine_presence_data <- function(results_list, registry) {
  imap_dfr(results_list, function(result, slug) {
    meta <- registry |> filter(slug == !!slug)
    result$data |>
      mutate(
        country     = meta$country,
        country_qid = meta$country_qid,
        class_qid   = meta$class_qid,
        class_label = meta$class_label,
        slug        = slug,
        .before     = everything()
      )
  }) |>
    mutate(across(where(is.integer), ~ replace_na(.x, 0L)))
}

Sub-Saharan Africa — ADM2

Second-level administrative divisions for 46 Sub-Saharan African countries. Class QIDs were identified via P150 hierarchy chains on Wikidata and validated with direct P31 instance counts (June 2026).

Three countries are excluded:

  • Central African Republic — sub-prefecture class (Q2355265) has 0 instances on Wikidata.
  • Eswatini — no ADM2 class (tinkhundla) found on Wikidata.
  • Comoros — no ADM2 class found on Wikidata.
Note

Some ADM2 classes capture items that are technically ADM1 in their national system. For example, Kenya’s 47 counties are constitutionally ADM1, but there is no sub-county class populated on Wikidata. Sudan’s 19 states are similar. These are included as the finest available level.

coverage <- all_data |>
  group_by(country, adm_level) |>
  summarise(
    n_units = n(),
    pct_en = round(100 * sum(en, na.rm = TRUE) / n(), 1),
    pct_fr = round(100 * sum(fr, na.rm = TRUE) / n(), 1),
    pct_ar = round(100 * sum(ar, na.rm = TRUE) / n(), 1),
    pct_sw = round(100 * sum(sw, na.rm = TRUE) / n(), 1),
    .groups = "drop"
  ) |>
  pivot_longer(
    cols      = starts_with("pct_"),
    names_to  = "language",
    values_to = "pct"
  ) |>
  mutate(
    language = recode(language,
      pct_en = "English", pct_fr = "French",
      pct_ar = "Arabic", pct_sw = "Swahili"),
    language = factor(language, levels = c("English", "French", "Arabic", "Swahili")),
    label    = paste0(round(pct), "%"),
    country  = reorder(country, pct, FUN = max)
  )

Notes on class selection

  • Kenya: Counties (47) are constitutionally ADM1. No sub-county class is populated on Wikidata, so counties serve as the finest available unit.
  • Sudan: States (19) are ADM1. Districts (Q505830, 202) are used as ADM3.
  • South Africa: District municipalities (47) are ADM2; local municipalities
    1. are ADM3.
  • DRC: Communes (74) as ADM2; territories (146) as ADM3. Provinces (32) are ADM1.
  • Mali: Communes (706) — unusually large ADM2 due to Mali’s flat hierarchy.
  • Nigeria: LGAs (817) at ADM2; wards (3,326) at ADM3 — both are large fetches.
  • Tanzania: Districts (199) at ADM2; wards (4,187) at ADM3 — wards are the single largest class in this analysis.
